## Modelo

```markdown
# NNNN. Título

- Status: Proposto | Aceito | Substituído | Descartado
- Data: AAAA-MM-DD

## Contexto

O problema e as restrições.

## Opções consideradas

- Opção A
- Opção B

## Decisão

O que foi escolhido e por quê.

## Consequências

O que fica mais fácil, o que fica mais difícil, o que precisa ser feito.
```
